# GeoIntel

Geospatial and network lookup suite in vanilla JavaScript with Leaflet. None of the data sources needs an API key.

## Features

- **Device GPS and live tracking:** coordinates, accuracy radius, altitude, speed, bearing and reverse-geocoded address
- **IP lookup:** resolve an IPv4, IPv6 or domain (or your own public IP) to country, city, region, ISP, ASN, timezone and map position
- **Phone number lookup:** parse E.164 numbers for country, region, carrier prefix, line type and timezone
- **Location simulator:** override your position by searching a place (Nominatim), typing coordinates or clicking the map
- **Distance calculator:** great-circle distance, bearing and walking/driving/flight time between any two known points
- **Weather and elevation:** current conditions from Open-Meteo
- **Batch plotting:** paste coordinate pairs or upload CSV/TXT, with centroid calculation and GeoJSON export
- **Coordinate converter:** DD, DMS, UTM, MGRS, Maidenhead grid and What3Words links
- **Map layers:** Esri dark canvas, street, satellite and topographic tiles
- **Export and share:** GPX for fixes, GeoJSON for batches, native share or clipboard for coordinates
